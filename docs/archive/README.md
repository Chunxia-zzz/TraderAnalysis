# archive/

存放**已明确过时、但需要留证据**的文档。

## 什么会进这里

| 情形 | 例子 |
|---|---|
| 描述的对象已完全消失，但过程有参考价值 | 某个已删除模块的完整设计稿 |
| 结论被彻底推翻，且已被新文档取代 | 旧版评分算法说明 |
| 历史事故的现场记录 | 某次数据损坏的排查全过程 |

## 什么**不**进这里

- **结论仍有效**的文档 —— 应该在 `modules/` / `reference/` 里继续维护
- **一次性核对快照** —— 放 `history/audits/`，那里允许"当时正确、现在过时"
- **已删除代码的说明** —— 直接删，不需要留档（git 历史里有）

## 规则

1. 进入本目录的文档，**顶部必须写一行**：`> ⚠️ 已归档（YYYY-MM-DD）：<为什么过时>`
2. 不再维护，不接受更新；发现错误就标注，不改正文
3. 索引（`docs/README.md`）**不列**本目录的内容 —— 避免有人当成现行文档
4. 允许删除：如果 git 历史已足够说明问题，直接 `git rm` 比放这里更干净
